# Pink Pulse

**Pink Pulse** — браузерный двухголосый музыкальный инструмент для исполнения короткой электронной композиции «Velvet Transit». Он создан как самостоятельный проект без библиотек и сборщиков: достаточно открыть `index.html` в современном браузере.

## Концепция инструмента

Pink Pulse — «дуэт в одном корпусе»: пользователь играет мелодию живым голосом, а второй голос удерживает пульс композиции через секвенсор. В отличие от обычного однотембрового синтезатора, здесь интерфейс сразу разделён на две музыкальные роли: **Lead** и **Bass**. Поэтому инструмент подходит не только для отдельных звуков, но и для быстрого эскиза законченного музыкального фрагмента.

Визуальный язык связан с концепцией: тёмный корпус напоминает концертный прибор, розовый цвет обозначает живой lead-голос, а лиловый — синхронизированный басовый голос. Светящиеся шаги показывают музыкальный пульс в реальном времени.

## Устройство и принцип работы

Проект использует нативный **Web Audio API**. После первого клика браузер разрешает звук, создаётся `AudioContext`, а каждый голос порождает собственные осцилляторы и огибающую громкости.

| Голос | Роль | Синтез | Управление |
| --- | --- | --- | --- |
| Voice A — Lead Synth | живая мелодия | sawtooth-осциллятор → low-pass filter → stereo pan → gain envelope | экранное пианино, клавиши `Z–M` и `Q–]`, параметры Cutoff, Resonance, Attack, Release, Reverb, Drive, Detune, Pan |
| Voice B — Bass Sequencer | басовый аккомпанемент | square-осциллятор → короткая амплитудная огибающая | 16 переключаемых шагов, Randomize, независимая громкость |

Кнопка **Play Set** запускает транспорт в темпе 124 BPM. Раз в шестнадцатую ноту проигрывается активный шаг секвенсора; активный шаг подсвечивается лиловой рамкой. Микшер управляет независимыми уровнями Lead, Bass, Space и Master. Клик по клавише фортепиано или соответствующая клавиша компьютера запускает ноту lead-голоса.

## Как запустить

1. Скачать или клонировать репозиторий.
2. Открыть `index.html` в Chrome, Firefox или Safari. Для стабильной разработки лучше запустить локальный сервер:

   ```bash
   python3 -m http.server 4173
   ```

3. Перейти в браузере по `http://localhost:4173`.
4. Нажать **Play Set** — это необходимо из-за политики браузеров для Web Audio.

Никакие `npm install`, ключи API или сторонние сервисы не нужны.

## Музыкальная часть: Velvet Transit

Эскиз построен в тональности **C minor**, темп — **124 BPM**, размер — 4/4. Басовый голос повторяет 16-шаговый паттерн с опорными нотами `C2 — G2 — A♭2 — E♭2`. Над ним исполняется короткая мелодия lead-голосом: `C4 — E♭4 — G4 — A♭4 | G4 — E♭4 — D4 — C4`.

Такой материал специально написан под возможности инструмента: повторяющийся бас демонстрирует секвенсор, а мелодия — живую клавиатуру, фильтр и огибающую голоса A. Во время исполнения можно открывать Cutoff и увеличивать Reverb для развития формы.

## Прототипы и интерфейс

1. **Первый функциональный прототип**: два Web Audio голоса, Play/Stop, ручная клавиатура и 16-шаговый бас.
2. **Визуальный макет**: отдельный редактируемый экран в Figma; для повторяющихся элементов созданы компоненты ручки, шага секвенсора и клавиши.
3. **Текущая версия**: розово-графитовый интерфейс с микшером, пресетом, управлением темпом и явным разделением двух голосов.

## Использование ИИ

ИИ использовался как инструмент совместной разработки: для исследования учебных примеров Tone.js/Web Audio, проектирования структуры двухголосого инструмента, генерации редактируемого Figma-макета и реализации HTML/CSS/JavaScript.

Подробная история промптов и решений находится в [docs/ai-process.md](docs/ai-process.md). Исходный код, музыкальные решения и финальная проверка были вручную просмотрены и протестированы автором проекта.
